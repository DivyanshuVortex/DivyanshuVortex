AI-powered developer assistant and CLI that provides autonomous code generation, semantic code search, GitHub issue solving, multi-agent PR reviews, and Hybrid RAG. Built with TypeScript, SQLite, BM25, vector search, and LLM APIs.
- **npm:** https://www.npmjs.com/package/@vortex-ai/cli
- **Repository:** https://github.com/DivyanshuVortex/vortex
